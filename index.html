基本的な使い方

ファイルを作る・開く

  • ファイル一覧の右上の ＋ から、新規ファイル・新規フォルダの作成や、「ファイル」アプリからの読み込みができます。
  • ファイルを長押し（Mac では右クリック）すると、名前の変更・共有・削除ができます。
  • 開いたファイルは画面上部にタブとして並び、タップ（Mac ではクリック）で切り替えられます。

編集画面

  • 右上の 🔍 で検索・置換、≡ でアウトライン、… でそのほかのすべての機能を使えます。Mac では、メニューバーからも同じ機能を使えます。
  • キーボードの上（Mac ではウインドウの下部）のツールバーには、TAB 入力・カーソル移動・元に戻すなどのボタンが並びます。入力中は、補完の候補もここに表示されます。
  • 画面下のステータスバーに、カーソルの行・桁、編集モード、文字コード、改行コードが表示されます。タップ（Mac ではクリック）すると切り替えられます。

設定

  • 共通設定（ファイル一覧の右上の … → 設定。Mac ではメニューバーの ツール → 共通設定、または ⌘,）：フォント、新規ファイルの文字コード、自動保存、バックアップ、キー割り当て、ツールバー、印刷設定など。
  • タイプ別設定（編集画面の … → タイプ別設定）：TAB 幅、折り返し、禁則処理、色、キーワード、アウトライン解析ルール、入力補完の単語、キーワードヘルプ辞書など。編集モードごとに設定できます。

iPhone・iPad・Mac の違い

機能はどの端末でも同じです。画面の大きさや操作方法に合わせて、画面の構成と操作が少し変わります。

iPhone での操作

  • 画面の切り替え：ファイル一覧と編集画面は1画面ずつ表示されます。ファイルをタップすると編集画面に進み、左上の戻るボタン（＜）でファイル一覧に戻ります。
  • 画面の向き：縦向きと横向きで使えます（上下逆さまには対応していません）。横向きにすると、1行に表示できる文字数が増えます。
  • 入力：画面のキーボードの上に、TAB 入力・カーソル移動・元に戻すなどのボタンが並ぶツールバーが出ます。細かいカーソル移動はこのボタンを使うと便利です。ボタンの種類と並び順は、共通設定 →「ツールバー」で変えられます。
  • タブ：開いたファイルのタブは画面上部に並びます。たくさん開いたときは、左右にスクロールして切り替えます。
  • アウトライン・ブックマーク一覧など：画面の下から半分の高さで開きます。上に引き上げると全画面になり、下に引き下げると閉じます。
  • 外付けキーボード：Bluetooth などのキーボードをつなぐと、キーボードショートカットも使えます。

iPad での操作

  • 画面の構成：横向きでは、ファイル一覧と編集画面が左右に並びます。縦向きなど画面が狭いときは編集画面が大きく表示され、左上のサイドバーのボタンでファイル一覧の表示・非表示を切り替えられます。
  • 画面の向き：縦・横・上下逆さまのすべての向きで使えます。
  • アウトライン・Grep・設定など：画面の中央に、小さなウインドウとして開きます。
  • 外付けキーボード：Magic Keyboard などをつなぐと、キーボードショートカットで操作できます。外付けキーボードを使っているときも、画面の下にツールバーと入力補完の候補が表示されます。

Mac での操作

  • 画面の構成：ウインドウの左にファイル一覧、右に編集画面が並びます。左上のサイドバーのボタンで、ファイル一覧の表示・非表示を切り替えられます。
  • メニューバー：「ファイル」「編集」「変換」「検索」「ツール」「マクロ」のメニューから、すべての機能を使えます。割り当てたショートカットは、メニューの項目の右に表示されます。
  • ツールバーと入力補完：ウインドウの下部に、TAB 入力・カーソル移動などのボタンと、入力補完の候補が並びます。
  • ファイルの操作：ファイル一覧のファイルやフォルダを右クリックすると、名前の変更・共有・削除ができます。
  • 書き出し：「共有・書き出し」では、保存先を選んでファイルのコピーを書き出します。
  • マクロ：メニューバーの「マクロ」には、キーマクロの記録・実行とマクロ一覧があります。登録したマクロは「マクロ一覧」から実行します。

共通

  • 右上の 🔍（検索）・≡（アウトライン）・…（そのほかの機能）、画面下のステータスバーは、iPhone・iPad・Mac で同じ位置にあります。
  • 同じ Apple ID なら、iPhone で作ったファイルを iPad や Mac で続けて編集できます（iCloud 同期）。
  • 一度入手すれば、同じ Apple ID の iPhone・iPad・Mac のすべてで使えます。

iCloud 同期

日本エディタで作ったファイルは iCloud Drive の「日本エディタ」フォルダに保存され、同じ Apple ID でサインインしている iPhone・iPad・Mac の間で自動的に同期されます。「ファイル」アプリや Mac の Finder の iCloud Drive からも開けます。

次の情報も同期されます。

  • 共通設定・タイプ別設定
  • マクロ、キーワードセット、印刷設定
  • 各ファイルのブックマーク、カーソル位置、編集モード
同期するには、iPhone・iPad では「設定」アプリ → 自分の名前 → iCloud、Mac では「システム設定」→ 自分の名前 → iCloud で、iCloud Drive をオンにしてください。iCloud を使えないときは、ファイルは端末内に保存されます。あとで iCloud を有効にしたら、日本エディタの設定画面から端末内のファイルを iCloud へ移動できます。

自動バックアップは端末内だけに保存され、同期されません。

マクロ

キーボードマクロ

編集画面の … → マクロ →「キーマクロの記録開始」から記録を始めます。文字の入力と、ツールバーやメニューから実行した編集コマンドが記録されます。記録した内容は「キーマクロ実行」で再生でき、JavaScript マクロとして保存することもできます。

JavaScript マクロ

マクロは JavaScript で書きます。… → マクロ → マクロ一覧から追加・編集できます。マクロ全体は1回の「元に戻す」で取り消せます。

// 選択した行の先頭に「> 」を付ける
const s = Editor.GetSelectedString();
Editor.InsertText(s.split("\n").map(l => "> " + l).join("\n"));
命令働き
Editor.GetText() / Editor.SetText(s)全文の取得・置き換え
Editor.GetSelectedString()選択中の文字列
Editor.InsertText(s)カーソル位置に挿入（選択範囲は置き換え）
Editor.AddTail(s)末尾に追加
Editor.DeleteBack()1文字削除
Editor.ReplaceAll(検索, 置換, {regex, ignoreCase, wholeWord})すべて置換（置換した数を返す）
Editor.Find(検索, {regex, ignoreCase, wholeWord, backward})次を検索して選択（見つかれば true）
Editor.GetLineCount() / Editor.GetLineStr(行)行数・行の内容（行は1から数える）
Editor.GetCursorLine() / Editor.GetCursorColumn()カーソルの行・桁
Editor.Jump(行) / Editor.MoveCursor(行, 桁)カーソルの移動
Editor.GetSelectionStart() / GetSelectionLength() / SetSelection(開始, 長さ)選択範囲の取得・設定
Editor.Command("コマンド名")編集コマンドの実行（例："duplicateLine"、"toUpper"、"sortAscending"）
Editor.GetFilename()ファイル名
Editor.GetClipboard() / Editor.SetClipboard(s)クリップボードの読み書き
Editor.Alert(s) / console.log(s)実行後にメッセージを表示

マクロから操作できるのは、開いているファイルとクリップボードだけです。ほかのファイルの読み書きや、インターネットへの接続はできません。

キーボードショートカット（初期設定）

Mac ではそのまま使えます。iPhone・iPad では、Bluetooth などの外付けキーボードをつないだときに使えます（画面のキーボードでは使えません）。共通設定 →「キー割り当て」で変更でき、1つのコマンドに複数のキーを割り当てられます。

キーボードの種類によっては、F キーや Home・End キーがないため使えないショートカットがあります。F キーは fn キーと一緒に押すと使える場合があります（Mac のキーボードでは、Home は fn＋←、End は fn＋→ です）。
⌃Space（入力補完）は、iOS・macOS の入力言語の切り替えと重なるため使えない場合があります。そのときは「キー割り当て」で別のキーに変更してください。

よくある質問

別の端末にファイルが同期されません

次の点を確認してください。

  • 両方の端末が同じ Apple ID でサインインしていること
  • iCloud Drive がオンになっていること（iPhone・iPad は「設定」アプリ、Mac は「システム設定」→ 自分の名前 → iCloud）
  • ネットワークにつながっていること。また、iCloud の空き容量が足りていること

ファイル一覧の上部に「iCloud で同期中」と表示されていれば、iCloud を使っています。「この端末のみに保存」と表示されているときは、iCloud を使えない状態です。同期には数分かかることがあります。

文字化けしています

編集画面の …（Mac ではメニューバーの「ファイル」）→「文字コードを指定して開き直す」で、正しい文字コード（Shift_JIS、EUC-JP など）を選んでください。画面下のステータスバーの文字コード表示をタップしても選べます。

保存すると「?」に置き換わる文字があります

保存する文字コードで表せない文字（例：Shift_JIS のファイルに入れた絵文字）は「?」に置き換わります。ステータスバーの文字コード表示をタップして、保存する文字コードを UTF-8 などに変更してください。

「ファイルの競合」と表示されました

同じファイルを複数の端末でほぼ同時に編集すると表示されます。「この端末の内容を残す」か「他の端末の内容を使う」を選んでください。

前の内容に戻したい

自動バックアップがオンのとき（初期設定はオン）は、保存の前の内容が端末内にバックアップされています。ファイル一覧の右上の … →「バックアップ」から内容を確認し、新しいファイルとして復元できます。保存しておく世代数は共通設定で変えられます。

編集中の内容は、「元に戻す」でも戻せます。

ファイルはどこに保存されていますか？

iCloud を使っているときは、iCloud Drive の「日本エディタ」フォルダです。iPhone・iPad では「ファイル」アプリ、Mac では Finder の iCloud Drive から見られます。iCloud を使っていないときは、iPhone・iPad では端末内の「このiPhone（iPad）内」→「日本エディタ」フォルダ、Mac ではアプリ専用の保存場所に保存されます。

パソコンのファイルを編集したい

Mac 版の日本エディタで直接編集できます。Windows パソコンなどからは、iCloud Drive の「日本エディタ」フォルダにファイルを置くと、日本エディタで開けます。また、ファイル一覧の ＋ →「『ファイル』から読み込む」を使うと、他の場所にあるファイルを取り込めます。

対応していない機能はありますか？

iOS・macOS の仕組み上、次の機能には対応していません。

  • 矩形（箱型）選択
  • アプリの常駐
  • 複数のウインドウ（Mac）。ファイルはタブで切り替えてください
  • VBScript などの JavaScript 以外の言語で書いたマクロ
  • UTF-7 の読み書き
